# Hotel Reservation System

A simple Java-based Hotel Reservation System that allows users to manage hotel bookings, guest records, and room reservations using Object-Oriented Programming concepts.

---

## Features

- Add new guests
- Book hotel rooms
- View guest details
- Manage room reservations
- Check room availability
- Simple console-based interface
- Uses OOP concepts:
  - Classes & Objects
  - Inheritance
  - Encapsulation
  - Abstraction
  - Polymorphism

---

## Technologies Used

- Java
- VS Code / NetBeans
- OOP Concepts
- Scanner Class for User Input

## How to Run

### 1. Clone Repository

```bash
git clone https://github.com/Mudassir-dev12/Hotel_Management_System_In_java.git
```

### 2. Open Project Folder

```bash
cd hotel-reservation-system
```

### 3. Compile Java Files

```bash
javac *.java
```

### 4. Run Program

```bash
java Main
```
